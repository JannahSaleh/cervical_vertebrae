CERVICAL VERTEBRAE WEBSITE
==========================

Files:
- index.html       Main landing page
- project.html     Page opened by the Enter Project button
- css/style.css    Responsive design and styles
- js/main.js       Small JavaScript interaction file
- assets/medical-hero.png  Generated visual used in the design

How to run on Mac:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open it in Safari or Chrome.
4. Click Enter Project to open project.html.

No installation or server is required. An internet connection is only needed
for the optional Google Fonts import; the website otherwise works locally.
